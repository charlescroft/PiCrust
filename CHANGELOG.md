# Changelog

All notable changes to PiCrust are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and releases use [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Every GitHub release embeds the matching section from this file, plus a
download table and installation instructions generated by
`scripts/release-notes.sh`.

## [1.7.3] - 2026-11-25

### Added

- **Unified Background Tasks & Live Stream Sub-View (`types.rs`, `session_controller.rs`, `app_state.rs`, `chat/mod.rs`, `i18n.rs`).**
  - Added unified `background_task` support (`background-tasks` extension widget + generic `background`/`isDaemon` tool detection) in the top-left **Subagents** dropdown with a `[Background Task]` / `[后台任务]` prefix.
  - Clicking any subagent or background task switches the current chat pane directly into a live streaming output view with a top-left **Back** arrow to return to the main conversation; switching sessions or workspaces automatically resets to the main conversation.
  - Added built-in adapter for `pi-background` (`bg_run`, auto-backgrounded `bash`, `bg_kill`) with live log tail streaming.
- **Extension Dependencies Documentation (`README.md`, `README.zh-CN.md`).**
  - Documented optional/recommended Pi ecosystem extensions (`pi-subagents`, `pi-background`, `@juicesharp/rpiv-todo`, `@juicesharp/rpiv-ask-user-question`, `pi-agy-link`) and one-line install commands.

### Changed & Fixed

- **Prevent Scroll Jump to Mid-History When Scrolling Right After Task Completion (`chat/mod.rs`).**
  - Replaced `s.reset(new_count, cx)` with `s.splice(new_count..old_count, 0, cx)` + `s.remeasure_items(...)` + `s.scroll_to_end(cx)` when message count shrinks on turn settlement, preserving measured item heights so scrolling up immediately after a task finishes no longer jumps to the middle of the conversation.

## [1.7.2] - 2026-11-25

### Changed & Fixed

- **File Links with Line Numbers Preview (`message_row.rs`).**
  - Fixed clicking file links containing line-number suffixes or URI fragments (such as `#L10-L20`, `#L42`, `:42`, `:42:10`, `:42-50`, and `?line=...`) failing to open in the sidebar preview by stripping line specs while preserving Windows drive letters (`C:`).
- **Markdown Preview Switching & File Viewer Toolbar Polish (`file_viewer.rs`, `panels/mod.rs`).**
  - Always initialize `markdown_state` for Markdown files (even when a diff patch is present) and added a dedicated **Preview** (`预览`) tab so users can freely switch back from **Diff** or **Source** to rendered Markdown.
  - Removed the redundant filename/path label from the file viewer toolbar and added a hover tooltip showing the full filename on the File Viewer tab.
  - Unified toolbar button typography and padding (`.small().h(px(24.))`) and updated the **Mention** (`引用`) button to display the `@` icon (`AtSignIcon`) alongside its label.
- **Background & Minimized Window Power Optimization (`main.rs`, `app_state.rs`).**
  - Tracked window active/inactive state via `observe_window_activation` and dynamically throttled background loops when inactive/minimized: external JSONL polling backs off from `500ms` to `5s` (`15s` in deep idle after 2 minutes, with directory scans slowed from `3s` to `30s`/`60s`), sidecar health checks slow from `5s` to `30s` (`500ms` to `5s` while disconnected), and native scheduler checks slow from `30s` to `60s`.

## [1.7.1] - 2026-11-24

### Added

- **Antigravity (`pi-agy-link` v0.6.83) Settings Controls (`extensions_page.rs`, `types.rs`).**
  - Added per-account **Plan Tier** cycle button (`Auto → PRO → ULTRA → FREE → ENT`, `/agy plan`) in the Antigravity account pool list.
  - Added advanced **Quota Warmup** controls: **Run Now** trigger button (`/agy warmup run`), **Warmup Windows** (`weekly` / `5h` / `both`), **Fixed Interval**, **Max Probes / Run**, **Daily Time (HH:MM)**, and **Timezone (IANA)**.
  - Added **Orchestrator Overrides** settings group: **Planner Model**, **Planner Thinking Effort**, **Executor Model**, **Executor Thinking Effort**, and **Reset to Default** (`/agy orchestrator ...`).
  - Added **ACP Cache Metrics** status and **Report** / **Reset** buttons (`/agy cache-status`, `/agy cache reset`), plus draining/stray/slot-overwrite telemetry in the Transport Mode description.

### Changed & Fixed

- **Hide AGY Status Bar & Settings Menu When `pi-agy-link` Is Not Installed (`app_state.rs`, `status_bar.rs`, `settings/mod.rs`).**
  - Added `AppState::has_agy_link_installed()` to check active state, `agy-link` models, enabled plugins, and global/workspace extension directories so Windows/macOS/Linux users without `pi-agy-link` no longer see the `Loading AGY` status bar badge or the Antigravity settings menu.
- **Immediate Workspace & Session Model Sync on Session Switch & Prompt Dispatch (`app_state.rs`).**
  - Fixed `select_session` reading the wrong JSON path (`st_val["model"]` instead of `st_val["state"]["model"]`) when checking whether the sidecar session's model was stale or out of sync with the workspace/UI model, and ensured `restore_model_for_workspace` also runs when no local JSONL path is present.
  - Synced the currently selected composer model to the sidecar via `set_session_model` before dispatching a `prompt` on an existing session, eliminating cases where the UI displayed one model (e.g., Gemini) while the sidecar sent requests to a different model.
- **Preview / Right Panel Resize Drag Release (`workspace/mod.rs`).**
  - Fixed mouse capture getting stuck in resize mode when dragging the right preview panel handle to its maximum width (`760px`) by checking `ev.pressed_button != Some(MouseButton::Left)` in `on_mouse_move`, adding `.on_mouse_up_out(MouseButton::Left, ...)`, resetting `resizing_right` when the panel closes, and stopping propagation on handle `on_mouse_down`.

## [1.7.0] - 2026-11-24

### Added

- **Unified Settings Toast Feedback.**
  - Replaced inline hardcoded error text and status banners in the Settings Add/Edit dialog (`add_dialog.rs`) and Extensions/Plugins page (`extensions_page.rs`) with consistent bottom-right auto-dismissing success and error toasts (`show_success_toast` / `show_error_toast`).
- **Detailed Sidecar HTTP Error Surfacing.**
  - Updated `PiDaemonClient` (`post_json` and `install_skill`) to parse and surface structured JSON `error` messages (or response snippets) from non-2xx Sidecar responses instead of generic HTTP status errors.

### Changed & Fixed

- **Skill Installation in Bundled macOS App (`dist-sidecar/server.mjs`).**
  - Fixed HTTP 500 (`spawn npx ENOENT`) when installing skills from a Finder-launched `.app` bundle on macOS by adding Homebrew Apple Silicon (`/opt/homebrew/lib/node_modules/npm/bin`) and Intel (`/usr/local/lib/node_modules/npm/bin`) `npx-cli.js` lookup paths in `findNodeCliScript`.
  - Enriched `runNpx` child process `PATH` with `dirname(execPath)`, `/opt/homebrew/bin`, and `/usr/local/bin`, passed `-y` to `npx`, extended the install timeout to 120s (125s client-side), and broadened install success detection.
- **Chat Composer & `@` File Picker.**
  - Added a short Enter-key suppression window (`suppress_enter_until`) after confirming a slash command or `@` file picker entry so pressing Enter to select an item does not accidentally submit the message.
  - Fixed `@` file picker keyboard scroll offset when navigating directories with a parent (`..`) row and ensured scrolling to the bottom on the last item.
  - Included hidden and gitignored project files (e.g., `.env`, local config/build artifacts) in `@` fuzzy file search (`native_index.rs`) while continuing to skip noisy directories (`.git`, `node_modules`, `target`, `.next`, `.next-desktop`, `dist`, `.venv`, `__pycache__`, `.DS_Store`).
- **File Explorer & Questionnaire UI.**
  - Added a 3-second reload debounce (`last_reload_at`) to `FileExplorerPanel` to avoid redundant directory tree rebuilds when the active working directory has not changed.
  - Included `title` and `options` in extension UI request deduplication (`AppState` and `QuestionnaireView::has_same_content`) and matched active questionnaire views strictly by `request_id` so distinct consecutive prompts are not dropped.
  - Removed the `560px` max-width cap on `QuestionnaireInput` so freeform answers span the full card width.

## [1.5.0] - 2026-11-18

### Added

- **Workspace Notes, Credentials & Workflows.**
  - Added dedicated sidebar quick-access buttons (inverted-triangle layout with hover tooltips) and native modals/panels for **Notes** (`notes_modal.rs`), **Credentials** (`credentials_modal.rs`), and **Workflows** (`workflows_panel.rs`), backed by `workspace_extras.rs` and Sidecar APIs.
  - Integrated Notes, Workflows, and Credentials into the in-chat / sidebar search (`find_bar.rs`) with `Esc` support to dismiss search cleanly.
- **Scheduled Task Session Reuse & Repeated Prompt Folding.**
  - Wired `executionTarget` (`"new"` vs `"reuse"`) from the Scheduled Tasks editor through `ScheduledTask` and Sidecar's `executeRun` / `liveRunnerDeps.startSession` so tasks configured to reuse conversations resume their previous session instead of creating a new one each run.
  - Collapsed repeated scheduled-task user prompts (occurrence #2+) into clickable horizontal divider cards in the chat timeline while keeping the first prompt expanded.
- **Manual Compaction & Context Breakdown.**
  - Added context menu manual compaction (`/compact` and UI trigger) and context breakdown progress bar in the session inspector, plus bottom-right error toasts for compaction failures.
- **Model Template Presets & Action Toasts.**
  - Added context window and max output preset dropdowns to the model configuration template, colored status/tier tags in Antigravity account settings, and toast notifications for create/update/delete actions.

### Changed & Fixed

- **Markdown & Chat Rendering.**
  - Fixed CJK bold delimiter rendering (`**...**` adjacent to CJK punctuation or inline code) so bold text renders cleanly without stray asterisks.
  - Fixed search bar floating label overlap with chat content and enabled `Esc` to cancel search.
  - Enabled inline play-continue on settled last turns, retry with JSONL pruning for empty failures, and hardened temporary chat badge/workspace detection.
- **Scheduled Tasks & Models.**
  - Fixed HTTP 400 error when creating scheduled tasks, fixed saving tool presets (`default` / `full`) with write acknowledgement, and filtered the scheduled task model selector to match the chat window's visible models.
  - Moved scheduled task error feedback to bottom-right auto-dismissing toasts instead of inline hardcoded banners.
- **App Lifecycle & Persistence.**
  - Persisted session archive state, improved window restore / idle wake handling, and refined thinking block collapse behavior.

## [1.4.0] - 2026-11-16

### Added

- **New Session Dropdown Menu & Multi-Mode Workflow.**
  - Revamped the top-left New Session button into a dropdown menu with clear creation modes: **Chat** (standalone persistent dialogue), **New Subproject** (native directory picker for project workspaces), and **Temporary Chat** (disposable isolated dialogue).
  - Bilingual i18n support for all dropdown actions and menu entries.
- **Temporary Chats with Automatic Sandbox Lifecycle & 24h Expiration.**
  - Seamless integration with Sidecar `/api/chat-workspace` (`~/.pi/agent/chats`) allocating isolated disposable workspaces (`~/.pi/agent/chats/<timestamp>-<id>/`) for throwaway tasks.
  - 24-hour time-to-live (TTL) expiration tracking with automatic startup garbage collection and cascade disk cleanup of JSONL logs and isolated folders.
  - Sidebar clock badges and status bar indicators for temporary sessions, complete with context menu actions to **Keep as Chat** (`promote_temp_chat`) or **Release Now** (`release_temp_chat`).
- **Standalone Chat Workspace Aggregation & Lazy Disk Provisioning.**
  - Unbound standalone chats from previous project working directories, routing transcript storage into a clean, aggregated directory to eliminate `~/.pi/agent/sessions/` fragmentation.
  - Zero-draft disk footprint: folders and files are lazily allocated only upon message dispatch or file creation.
  - Cross-platform path normalization for reliable Chat workspace detection across macOS, Linux, and Windows separators.

## [1.3.0] - 2026-11-16

### Added

- **Antigravity (AGY) Management Console & Multi-Account Pooling.**
  - Rebuilt the Antigravity management console on native `gpui-kit` settings architecture with tabbed navigation and dedicated account cards.
  - Added direct copyable OAuth login links alongside browser re-authentication for primary and isolated accounts.
  - Duplicate account detection with visual tags and distinct primary/isolated status indicators.
  - Color-coded quota capsules and real-time quota progress bars with tier detection (5H, 7D, Argon, Pro, and Ultra).
  - Dedicated Model Visibility table with smooth scrolling and instant synchronization with the external model picker across account switches.
  - Dynamic thinking effort level synchronization reflecting the active model's reasoning capabilities.
  - Non-intrusive background refresh: eliminated disruptive chat view jumps, reloads, and false-positive running indicators during `/agy` refresh operations.
- **Session & Branch Navigation.** Chronological branch sorting in the conversation tree for intuitive session history exploration, dynamic branch indicators, and seamless branch switcher integration.
- **Provider & Extension Management.** Confirmation workflow with loading spinners and thorough catalog cache cleanup on provider deletion, plus smooth plugin uninstallation feedback with robust status management.

### Changed & Fixed

- **Persistent Error Reporting in Dialogue History.**
  - Removed the ephemeral error dismiss button from assistant turn cards. Real errors from model invocations and system responses now stay visible and persistent in the conversation history across program restarts, ensuring diagnostic state is never lost.
  - Retained essential actions on error cards: one-click error copying to clipboard, expand/collapse details toggle, and context window limit compaction.
- **Sidecar Connectivity & Resilience.** Permanent connection model with automatic multi-stage health recovery, zero-configuration local loopback trust, and eliminated idle timeouts.
- **Cross-Platform Performance & Stability.** Eliminated Windows ConPTY terminal memory spikes, restricted directory scanners on startup, and removed background console flashing via `CREATE_NO_WINDOW`.

## [1.2.0] - 2026-11-15

### Added

- **Open-sourced `pi-agy-link` extension (`extensions/pi-agy-link`).** Adapted
  from `dsh-agy-link` into a standalone standard Pi extension driving the
  official `agy` CLI with multi-account pooling, sequential drain, quota-expiry
  rotation, per-account proxy, loopback OAuth, and `agy_ask` tool.
- **Full CLI/TUI parity for `/agy`.** Every UI datum is queryable from the
  command line (`/agy status`, `/agy details [account]`, `/agy models`,
  `/agy refresh`, `/agy add`, `/agy primary`, `/agy switch`, `/agy remove`,
  `/agy proxy`).
- **Native GPUI Antigravity Pool & Account Details UI.** Added a clickable
  `AGY` status bar badge and a dedicated modal (`src/panels/agy_link_modal.rs`)
  with color-coded 5H/7D/Argon quota capsules and per-model quota breakdowns
  adapted from `AGM-Rust`.
- **Info notification surfacing.** `extension_ui_request` `notify("info")`
  messages now surface in the status banner for extension command feedback.

## [1.1.0] - 2026-11-15

### Added

- **Built-in provider catalog with 30+ providers.** The Add Provider dialog now
  lists OpenAI, Anthropic, Google Gemini, xAI (Grok), DeepSeek, Mistral, Groq,
  Together AI, Fireworks AI, Cerebras, NVIDIA NIM, Hugging Face, Baseten,
  Ant Ling, OpenRouter, Vercel AI Gateway, SiliconFlow, Volcengine Ark
  (Doubao), Moonshot AI (Kimi) international/CN, MiniMax international/CN,
  Z.AI (GLM) international/CN, Qwen (DashScope international/CN), Xiaomi MiMo,
  Kimi For Coding, GitHub Copilot, Ollama, LM Studio, and vLLM.
- **Automatic model discovery.** Saving a custom provider (or adding a provider
  API key) downloads its `GET /models` list and lets you pick which models to
  add — no more typing model ids by hand. Discovery also works while the
  sidecar is offline.
- **Configured-provider badges and key updates** in the provider picker, so a
  provider no longer disappears once it has been configured.
- **Curated first-run models** for every credentialed provider. These act as a
  fallback only when no live model list is available; pi's own catalog always
  wins when the sidecar reports models.
- **Windows application icon.** `build.rs` embeds `assets/icon.ico` as icon
  resource id 1 (the resource gpui's Windows backend loads for the window and
  taskbar), and the title bar now shows the PiCrust brand mark.

### Changed

- **New installs start in the white "Default Light" theme.** Dark mode and the
  themed palettes remain one click away in Settings → General.
- GitHub Releases now publish the raw platform artifacts with the version as
  the filename suffix (for example `PiCrust-windows-x64-1.1.0.exe`), upload a
  `SHA256SUMS-<version>.txt`, and use complete release notes generated from
  this changelog.
- The native Rust engine resolves the endpoint and API-key environment variable
  from the provider catalog, so OpenRouter, DeepSeek, xAI, Groq, and other
  built-in providers work even without a `models.json` entry.
- Provider discovery is no longer gated on the sidecar connection; it is a
  direct HTTPS request from the desktop to the configured base URL.

### Fixed

- **Removed the fake demo workspace and fake model.** A fresh install now shows
  the real empty state instead of an "Architecture Overview" session, seeded
  todos, and a Claude model that was never configured. Sending a prompt without
  a model shows an actionable error instead of a fabricated assistant reply.
- **Provider list no longer collapses to three entries.** Sidecar provider data
  is merged into the static catalog instead of being ignored once the offline
  fallback had populated the list, which previously hid OpenRouter and most
  other providers.
- Deleted sessions and removed models no longer linger after a refresh because
  empty authoritative lists are now applied.
- The window/taskbar icon is present on Windows instead of the generic
  executable icon.

## [1.0.1] - 2026-11-15

### Fixed

- Windows terminal no longer leaks memory while switching panels.
- Sidecar/SSE connections reconnect seamlessly instead of dropping the
  persistent session.
- Startup no longer scans eagerly or re-parses every JSONL transcript in the
  background.
