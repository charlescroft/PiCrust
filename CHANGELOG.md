# Changelog

All notable changes to PiCrust are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and releases use [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Every GitHub release embeds the matching section from this file, plus a
download table and installation instructions generated by
`scripts/release-notes.sh`.

## [1.2.0] - 2026-11-15

### Added

- **Open-sourced `pi-agy-link` extension (`extensions/pi-agy-link`).** Adapted
  from `dsh-agy-link` into a standalone standard Pi extension driving the
  official `agy` CLI with multi-account pooling, sequential drain, quota-expiry
  rotation, per-account proxy, loopback OAuth, and `agy_ask` tool.
- **Full CLI/TUI parity for `/agy`.** Every UI datum is queryable from the
  command line (`/agy status`, `/agy details [account]`, `/agy models`,
  `/agy refresh`, `/agy add`, `/agy primary`, `/agy switch`, `/agy remove`,
  `/agy proxy`).
- **Native GPUI Antigravity Pool & Account Details UI.** Added a clickable
  `AGY` status bar badge and a dedicated modal (`src/panels/agy_link_modal.rs`)
  with color-coded 5H/7D/Argon quota capsules and per-model quota breakdowns
  adapted from `AGM-Rust`.
- **Info notification surfacing.** `extension_ui_request` `notify("info")`
  messages now surface in the status banner for extension command feedback.

## [1.1.0] - 2026-11-15

### Added

- **Built-in provider catalog with 30+ providers.** The Add Provider dialog now
  lists OpenAI, Anthropic, Google Gemini, xAI (Grok), DeepSeek, Mistral, Groq,
  Together AI, Fireworks AI, Cerebras, NVIDIA NIM, Hugging Face, Baseten,
  Ant Ling, OpenRouter, Vercel AI Gateway, SiliconFlow, Volcengine Ark
  (Doubao), Moonshot AI (Kimi) international/CN, MiniMax international/CN,
  Z.AI (GLM) international/CN, Qwen (DashScope international/CN), Xiaomi MiMo,
  Kimi For Coding, GitHub Copilot, Ollama, LM Studio, and vLLM.
- **Automatic model discovery.** Saving a custom provider (or adding a provider
  API key) downloads its `GET /models` list and lets you pick which models to
  add — no more typing model ids by hand. Discovery also works while the
  sidecar is offline.
- **Configured-provider badges and key updates** in the provider picker, so a
  provider no longer disappears once it has been configured.
- **Curated first-run models** for every credentialed provider. These act as a
  fallback only when no live model list is available; pi's own catalog always
  wins when the sidecar reports models.
- **Windows application icon.** `build.rs` embeds `assets/icon.ico` as icon
  resource id 1 (the resource gpui's Windows backend loads for the window and
  taskbar), and the title bar now shows the PiCrust brand mark.

### Changed

- **New installs start in the white "Default Light" theme.** Dark mode and the
  themed palettes remain one click away in Settings → General.
- GitHub Releases now publish the raw platform artifacts with the version as
  the filename suffix (for example `PiCrust-windows-x64-1.1.0.exe`), upload a
  `SHA256SUMS-<version>.txt`, and use complete release notes generated from
  this changelog.
- The native Rust engine resolves the endpoint and API-key environment variable
  from the provider catalog, so OpenRouter, DeepSeek, xAI, Groq, and other
  built-in providers work even without a `models.json` entry.
- Provider discovery is no longer gated on the sidecar connection; it is a
  direct HTTPS request from the desktop to the configured base URL.

### Fixed

- **Removed the fake demo workspace and fake model.** A fresh install now shows
  the real empty state instead of an "Architecture Overview" session, seeded
  todos, and a Claude model that was never configured. Sending a prompt without
  a model shows an actionable error instead of a fabricated assistant reply.
- **Provider list no longer collapses to three entries.** Sidecar provider data
  is merged into the static catalog instead of being ignored once the offline
  fallback had populated the list, which previously hid OpenRouter and most
  other providers.
- Deleted sessions and removed models no longer linger after a refresh because
  empty authoritative lists are now applied.
- The window/taskbar icon is present on Windows instead of the generic
  executable icon.

## [1.0.1] - 2026-11-15

### Fixed

- Windows terminal no longer leaks memory while switching panels.
- Sidecar/SSE connections reconnect seamlessly instead of dropping the
  persistent session.
- Startup no longer scans eagerly or re-parses every JSONL transcript in the
  background.
